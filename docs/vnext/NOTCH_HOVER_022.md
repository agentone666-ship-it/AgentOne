# 刘海悬停与界面改版（0.2.2）

## STATUS

需求：鼠标移到 Mac 刘海时自动展开，并改善界面。已实现原生窗口与悬停状态机，更新同一路径的本机 App；保持录音、原音导出、自动续录和本机转写未启用。

## DECISIONS

参考产品的交互与视觉层级，不复制其业务功能：

- [Droppy 官方交互说明](https://getdroppy.app/docs/notch)：悬停展开、离开后延迟收起；有刘海贴合硬件，无刘海使用胶囊。
- [NotchNook 官方介绍](https://getnotchnook.com/)：从刘海向下展开的集中工具表面。
- [Boring Notch 官方仓库](https://github.com/TheBoredTeam/boring.notch)：轻量黑色面板、按内容组织快捷入口。

## CHANGES

- 用 NSScreen.safeAreaInsets、auxiliaryTopLeftArea / auxiliaryTopRightArea 计算真实刘海尺寸。优先内置刘海屏幕，覆盖摄像头所在区域作为悬停入口；外接无刘海屏使用顶部胶囊。
- 原生面板顶部锚定屏幕顶边，内容绕开摄像头；展开宽 480 pt，收起时仅显示声音图标与真实状态点。
- 每 80 ms 读取公开 NSEvent.mouseLocation，移入停留 160 ms 展开，移开 600 ms 收起。无需新增辅助功能或输入监听权限；窗口使用菜单栏上方层级。
- 进入展开区域后保持展开；重新进入取消待收起。固定、文本编辑、模态确认时保持打开；点击收起后必须移出再进入，避免立即弹回。
- 显式点击/菜单展开有短暂保持时间。窗口切换时清空旧的离开计时，避免点击后立即被上一次计时收起。
- 支持系统“减少动态效果”；普通模式 220 ms 尺寸动画。普通容器承载 SwiftUI，由 AppKit 控制窗口尺寸，避免收起后的固有尺寸锁死。
- 窗口初始焦点放在中性容器，不自动聚焦地点或搜索框；真正编辑时才暂停自动收起。
- 「记录」页使用两路声音卡片、地点和主操作；「回忆」页独立搜索和原音回放；「设置」页集中权限相关偏好和数据操作。
- 黑色背景、薄边框、底部圆角、薄荷色主操作，去掉首页的大量开关和技术说明。静态声音符号不冒充实时音量波形。

## TESTS

- 完整 Swift 测试 103 项通过，其中 IslandWindowTests 5 项：真实 NSPanel 反复展开/收起，刘海与无刘海几何，多屏坐标，悬停去抖与重入，保护状态恢复延时，以及注入指针样本后在没有点击的情况下改变真实面板尺寸。
- ZIP 打包门禁：签名、资源、自检、版本、未嵌入旧 Agent/Pi runtime、实际 MCP 子进程通过。
- 本机 CUA 检查：0.2.2 实际收起外观、展开记录页、图钉、回忆空状态和设置页；设置页确认自动续录 / 原音访问关闭，锁屏暂停开启，本机转写未启用。
- 悬停时序由状态机与真实窗口集成测试验证。CUA 没有纯鼠标移动 API，拖动不能代替真实用户悬停验收；不将该动作描述为硬件鼠标悬停实测。
- 没有借界面测试开始真实录音、启用 ASR 或批准任何系统权限。云端检查以 PR #2 最新提交的 Checks 为准。

## HANDOFF

- 本机路径：`~/Applications/AgentOne.app`，版本 0.2.2。旧 bundle 保存在本机 Backups 目录。
- 日常使用：鼠标移到刘海中央即可展开，移开自动收起；图钉可固定，右上箭头可收起；菜单栏仍保留展开入口。
- 首次录音仍由用户在「记录」页明确点击“开启录音”。长期录音和识别效果属于独立验收，不由本次界面修改证明。
