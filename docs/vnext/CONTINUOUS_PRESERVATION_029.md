# 0.2.9：原音持续保全，模型分析与保存分离

## STATUS

已安装签名的 0.2.9，本机“自动记录声音”开启，“持续保全”选中；重开应用后无需点录音即恢复 continuous_preservation。先用旧版手动持续保存覆盖开发等待期；安装/重开过程的中断已按实际停启保留。

## DECISIONS

用户在现场会议漏录后选择“优先不漏录：持续本机保存，模型做分段和标签”。当前策略取代 0.2.8 的默认智能触发；旧会议没有完整文件，不能补回，不把合成音测试当成真实会议验收。

- 默认保存策略为 preserve；自动启动后连续写混合音频。模型 wait、低分、nil、NaN、加载失败或未知输入都无权中断保全。手动暂停、锁屏/休眠偏好和真实存储/设备错误仍生效，不能承诺设备不可用时也能录到。
- 智能触发保留为可选，界面明确提示可能漏掉轻声/停顿会议。
- 默认约 60 秒封文件；Laya 活动变化稳定后可额外切片，至少间隔 15 秒。切片只封当前文件，下一帧按原时间继续写，不产生自动省略区间。声学标记只是最后一次观测，不等于整段内容总结。
- 已启用本机 ASR 时，Laya 可按转写生成工作/任务/日常/学习/媒体等预览标签；低分保留待确认。不生成无来源待办，不声称人物身份。预览检查来源哈希、转写版本和文本未变，不抢占宿主 analyze 任务。
- 主题预览存为 meta 中的独立派生记录，MCP 和本机 UI 可读；删除来源时一并清除。纯 ASR no_speech 明示“未识别语音”，不当作真实安静。
- 定位权限已由用户完成认证：总开关与 AgentOne 开启，其他应用开关均关闭；真实持续录音已有自动地点与坐标/精度/时间证据。

- 真机静置至少 4 个连续约 60 秒片段：均 sealed、原文件哈希正确、continuous_preservation、真实 core_location 证据齐全、后台 asr_no_speech 预览生成，automatic_wait 数量为 0；Laya 为 wait/unknown 时仍持续保存。正常退出/重开后状态为 recording，心跳更新，原音继续落盘。
- 本机缓存 Laya 的活动/主题 JSONL 协议均已真实运行；输入为合成文本，不能证明真实会议分类准确率。合成检索 benchmark 18/18，仍不代表真实 ASR 或会议召回。
