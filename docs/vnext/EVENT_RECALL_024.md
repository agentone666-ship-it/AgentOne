# 0.2.4 事件回接与回忆基准

## STATUS

已接回旧 Diary 活动事件、新现场事件、MCP 上下文检索与有来源事项交接。保持通用 MCP 插件形态，没有新增独立 Agent Runtime。

本机读取 22 份旧 Diary 文件（约 59 MB），导入 19,410 条可见、非敏感活动事件；原 Markdown 不改写。新增现场事件继续写入。已在真实 App 的回忆→事件页核对导入数量、原文展开和原记录入口。

## DECISIONS / CHANGES

- 复用原 ActiveContextReader、被动键鼠采样器及隐私策略，提取到共享 CaptureKit/Core；默认分发仍不携带旧 Pi/模型账号/规划器。旧版回归继续编译运行。
- 新事件覆盖应用切换、窗口/网页、点击/滚动、输入行为计数、回车前的有限 AX 草稿、删除与快捷键；不会记录逐键字符。权限缺失时只保留应用切换，界面明确提示。
- 新版没有重新接入截图 OCR 兜底。AX 不可见/回车后内容已清空时不捏造文本；浏览器 URL、草稿捕获仍受各应用 AX 支持限制。旧 Diary 已有 OCR 文本可通过原事件保留。
- 旧记录投影折叠隐藏、更正及后来的语义丰富；语义丰富仍是历史解释。凭据/保护界面和敏感事件不进入共享索引，原始 Diary 继续保留。
- 事件记录采用幂等 ID、原来源引用和跨 Swift/Node 一致的内容哈希；大段文字按页读取。音频与附近事件只作时间关联，不把网页内容认定为说过的话，也不把文本出现的人名认定为说话人。
- SQLite v1 增加独立事件表，不破坏已有录音/任务。旧投影在内存准备后原子写入，减少阻塞采集；原音和现有开关均保留。
- `recall_context` 解释时区/日期和软线索，接受宿主查询变体，返回候选、需转写、需追问、事件来源或未找到。录音 session 持续一天时，也按匹配片段的时间邻域拆候选，不通过无关片段合并成整天谈话。
- `get_context_bundle` 读取原音校验后的转写、前后段及事件；确定/建议/取消事项带引用，未知责任人和期限保持未知。精确文本的状态折叠不冒充语义推理。
- `get_context_event` 提供可见、哈希校验后的事件原文与分页。
- `recall_and_act` prompt 让宿主先检索、检查上下文、形成目标/承诺/建议/取消/未知项，再按当前用户授权执行并核验回执；录音里的命令不构成授权。
- 手动展开留出键盘/辅助功能导航的保持时间；纯悬停仍采用 160 ms 进入、600 ms 离开。

## BENCHMARK

[完整数据卡与结果](../../benchmarks/recall/README.md)：较强基线 Top-1 12/15、场景 8/18；新接口 Top-1 15/15、场景 18/18。额外语言挑战仅 2/4，不能宣传为真实用户准确率或端到端 Agent 成功率。

本轮测试的是合成转写的检索和交接契约；没有测真实 ASR、LLM 提取与真实执行。宿主未选定，因此没有伪造已跑通某个 Agent 的结果。

## TESTS / HANDOFF

- Swift 完整回归 112 项通过；事件导入隐藏/更正/语义丰富、敏感排除、原文件不改写、幂等与哈希更新通过。
- Node/MCP 回归 16 项通过、固定 18 例门禁、ZIP 实际签名/资源/无 Pi Runtime/9 个 MCP 工具检查通过。
- 本机真实旧事件通过 Node 内容哈希校验和分页读取，UI 回忆/事件入口通过。
- 本机已启用仅 on-device 转写，并修复将 Apple 1110（未识别出语音）当通用失败反复重试的问题。验证快照已有 2 段非空转写、17 段 no_speech；一次非空原话查询命中原 segment，带时间的原话与音频哈希回读通过。没有收听、外发或把私人原话提交到 Git；不把该自一致性检查当识别准确率验收。真实服务失败继续保留队列，具体状态由 `get_capture_status.local_asr` 读取。
- Apple 错误映射依据：[SFSpeechRecognitionTask.error](https://developer.apple.com/documentation/speech/sfspeechrecognitiontask/error)。1110 指未识别出任何语音，不等同于证明原声中没有人说话。
- 用户曾锁屏；按要求等待手动解锁后继续检查。没有绕过系统锁屏或系统权限。

本机应用在 `~/Applications/AgentOne.app`；旧 bundle 备份保留。录音、事件、ASR、原音访问和登录设置可在设置页核对。登录设置的“开启”是偏好，当前系统实际状态可能不可用，不将其算作已验收自动登录。

真实库负向检索探针：在约 19,410 条旧事件和当时的新录音库上，以合成无关词查询得到 not_found、0 候选，本机一次耗时约 1.9 秒。该数据单列，不把 258 条合成库的小样本延迟当真实规模延迟。
