# 0.2.11 静音文件清理

## STATUS

本地实现、155 项 Swift 测试、21 项 MCP 测试和 Release 打包检查通过。历史静音已清理；自动清理版本待 CI 和安装后核验。

## DECISIONS

连续采样和持久 PCM 恢复不变，整段文件封口后后台清理。保持有声文件全部采样与内部停顿，避免依赖模型触发导致漏掉对话开头。静音判断不使用 ASR no_speech、Laya 的 quiet 标签或文件时长。每声道、每约 20ms 解码窗都要低于 -65 dBFS RMS，且全文件采样峰值低于 -55 dBFS；至少 1 秒、完整可解码才允许清理。此门限保守保留较明显的环境底噪。

## CHANGES

- 新封口录音自动排队解码、哈希核验和清理；启动与每五分钟补扫旧静音候选。解码在独立低优先队列和独立数据库连接上，不占音频写盘队列。
- 只处理 sealed 文件，不碰 recording/incomplete；非空转写、已生成分析、用户修正、长期记忆引用和正在使用的租约保护原音。删除前在事务内再次验证状态、来源哈希与引用。
- 删除对应原音、PCM/sidecar/partial，取消转写任务。保留 silent_audio_discarded 时间记录与数值判据；不冒充设备断流。持久删除标记先于文件删除，残留文件下轮重试，崩溃恢复不会复活已清理的静音。
- CLI --prune-silence 默认预览，显式 --apply 执行清理；跨进程锁避免多个清理器重复执行。

## TESTS

真实 AAC 静音清理与重复执行；短暂低声单声道信号及首尾静音保留；错误旧音量摘要和 ASR no_speech 不等于静音；有文字/分析/有效租约保护；哈希改变拒绝删除；封口后的后台清理不依赖重启；持久标记后的残留文件可重试清理且不被崩溃恢复复活。

本机历史扫描：259 段候选，实际波形确认 251 段纯静音，另外 8 段保留。已删除 251 段，释放 27,009,256 字节；清理后复核 1,377 份保留文件的 SHA-256 不变，无静音删除来源仍挂起转写任务。清理期间原采集 PID 不变，控制心跳和真实 PCM 写盘继续。私有预览、清理与读回报告只保留在本机应用数据目录，未上传。

## HANDOFF

较明显的空调/风扇/耳机底噪不会按“无语音”粗暴删除；后续如需滤除背景噪声，需要单独评估低声对话误删风险。已有 630 秒完整采集验收仍有未通过项，本改动不改变其结论。
