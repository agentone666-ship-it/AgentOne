# AgentOne v0.2 隐私与数据边界

## 启动与录音

- 0.2.3 按自动记录需求默认启用：首次启动请求一次系统音与麦克风权限，系统授权后自动连续保存；0.2.5 起两种输入混合为一条录音。系统拒绝授权时不会假装在录音，不反复弹窗。
- 0.2.9 默认持续保全：只要采集在运行，就连续保存本机混合音频，包含安静片段。Laya 只提供活动标记与分文件建议，不能停录或丢弃。可另选有漏录风险的智能触发模式，才使用 10 秒内存预录和保存门限；手动暂停与锁屏/休眠规则始终优先。
- 休眠会暂停；锁屏默认暂停，可在岛上关闭该选项以尽量持续记录。解除阻止条件后仅恢复用户此前希望继续的录制；用户手动暂停有独立持久状态。
- 登录启动默认注册，系统需要额外确认时在设置中显示真实状态。关闭自动记录或手动暂停后，不因登录重新启动采集。强制结束进程可能产生不完整尾段，不伪装为完整录音。
- 不保存连续屏幕视频。ScreenCaptureKit 在这里用于系统音输入，麦克风使用 AVAudioEngine 输入，按主机时间混音后保存一条录音；极小的视频回调直接丢弃，不保存；界面中的应用信息只是现场线索，不证明发声来源。
- 周围人的录音告知与办公场景约定需要用户在开始日常记录前处理，产品不提供隐藏录音模式。

## 静默分析与宿主

- 本机 ASR 需显式启用，使用 requiresOnDeviceRecognition；不支持/不可用时保留待处理任务，不静默转到云端识别。
- Laya 多语言分类器仅在本机离线运行，接收声音活动描述与已启用本机 ASR 产生的转写，用于活动/主题预览，不直接读取原音、不上传原音或转写；SDK 和固定权重由显式安装脚本下载，App 启动只使用缓存。采集服务和 MCP 服务自身没有云模型调用。标签/事实/长期巩固由用户选择的宿主通过 MCP 处理。
- 接入宿主即允许它按工具范围读取文字证据；宿主可能使用云模型，不能保证资料永不离开电脑。
- 原始音频的 MCP resource 读取默认关闭，需在原生 UI 单独开启；已经交给宿主的资料无法自动收回。
- 队列离线、ASR 失败、模型失败和未处理分别可见，不通过失败后空结果冒充成功。

## 保存与删除

- Memory 目录、音频目录使用本机私有权限；数据库和音频文件设为 0600。没有实现应用级加密，不得宣传“已加密”。
- 不根据模型重要性或音频年龄自动删除原件。空间不足/写入失败会停止并提示，不假装一直录到了。
- “删除最近片段”会移除本机原音、转写、标签和派生内容，并使引用该来源的长期记忆失效。
- 删除新记忆来源不会让被替代的旧事实自动重新成为当前事实。
- 删除不等于 SSD、系统快照、备份或宿主副本的取证级擦除。删除失败的文件需用户检查 Memory 目录；界面会明确报告。
- 崩溃中未封口的尾段标为 incomplete，不自动作为完整证据交给分析器。

## 事实和推断

- 0.2.7 按用户要求改为系统 Core Location 自动获取，保存坐标、精度和采样时间，使用系统地址解析；可在设置关闭。仅在系统授权后采样，不用 IP 或网络名猜地点。精度不足、拒绝、失败或超过 10 分钟的旧位置保持未知；不能据此确认具体工位、房间或谁在场。原来的手动地点历史不改写。
- Apple ASR 不提供这里需要的可靠人物身份识别；说话人身份未知时保持未知，不默认建立声纹库。
- 模型标签、人物关系、任务和长期总结是带证据的解释。服务器校验引用、区间、来源哈希与版本，不能证明语义一定正确。
- 录音里的指令不形成当前用户授权；MCP 不提供执行录音中任务的行动工具。

## 当前不能承诺的边界

原音在识别前无法可靠判断是否包含密码、支付或敏感谈话。因此不能把旧版文字 Context 的敏感词过滤，宣传为新音频版已做到“敏感原声绝不落盘”。目前提供系统授权、自动记录开关、锁屏暂停、随手暂停和删除；应用级排除、加密、声纹与完整的长期保留管理仍需后续实现/验收。

真实系统授权、全天采集、输入设备切换、睡眠恢复、本机 ASR 质量和长期资源占用还需设备实测，见实现状态文档。

## 事件与旧 Diary（0.2.4）

- 按事件记录需求启用被动应用/窗口/网页/交互观察，缺权限时只保留应用切换。键盘采样仅提供行为与计数，不保存逐键字符；有限 AX 草稿只有在回车线索时才作为事件文本保留，不保证消息实际已发送。
- 复用原敏感界面/凭据过滤。新采集没有截图 OCR 兜底，旧 Diary 已存的 OCR/原话可进入可见非敏感事件投影。
- 导入不改写旧文件；隐藏、更正和模型解释保留其含义。MCP 事件正文按页读取，包含来源与内容哈希。
- 与录音时间相近的应用或网页只是线索，不能证明说话内容、位置或说话人身份。
- 合成 benchmark 不含真实用户原音/原话；本机同步的旧记录未提交到 Git，未上传到云模型。

## 合并录音（0.2.5）

按用户最新要求，系统音与麦克风不再分别生成文件。新录音为一个立体声混合流，每个输出声道都包含系统音和麦克风；不做回声消除或声纹识别。混音后的声音无法还原成原来的独立输入。

两种输入按时间对齐，缺少某种输入的时段用零值占位，不把后来的声音提前拼接。输入缺口、迟到帧与混音参数保留在覆盖记录和元数据中。旧分轨文件与已有转写/记忆关系不删改；本机升级前另做数据库备份。

## Agent 连接（0.2.7）

设置中推荐导出本机插件（包含工作流与 MCP），也可复制 MCP 配置。插件导出仅复制程序与说明，不复制音频、数据库、坐标内容或凭据；配置中包含本机程序和 Memory 目录路径。自检不冒充 Agent 连接，最近连接来自实际宿主 initialize 握手，宿主名称只是自报信息，不作为身份认证。导入插件不改变原音访问设置。系统坐标和地址属于现场资料，连接的宿主可能在推理中使用并交给其云模型。

## 本机预览标签（0.2.9）

Laya 标签仅是模型推断，低置信显示待确认；无识别语音只是 ASR 结果，不证明真实安静。预览绑定原音哈希和转写版本，回写前再次检查来源，删除音频时一并移除。它不将分析任务标为完成，也不代替宿主核对原话、提取待办或授权实际行动。
