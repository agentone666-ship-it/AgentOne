# AgentOne 隐私与数据边界

AgentOne 的能力来自 Context，因此隐私不是设置页里的附加选项，而是采集和模型架构的前置约束。

## 数据归属

- AgentOne 不要求产品账号。
- 用户选择本地 Agent Home，并拥有其中的日记、证据、Memory 与 Skills。
- 删除应用不会自动上传或接管 Agent Home；用户也可以自行备份和迁移该目录。
- 云模型只是一种可选计算路径，不是用户数据的所有者。

## 采集类型

| 类型 | 例子 | 默认行为 |
| --- | --- | --- |
| 行为语义信号 | 滚动、主点击、开始输入、回车、删除节奏、切换窗口、idle/resume | 本地采集并先聚合为持续状态 |
| Accessibility Context | 应用名、窗口标题、URL、可见正文、焦点元素、选中文本 | 需要系统授权；受敏感策略过滤 |
| 关键截图 | 回车输入框、任务切换前现场 | 需要屏幕录制授权；事件触发、局部保存 |
| OCR 文本 | 输入区域内本次提交的文字 | 本地识别；敏感检查后才可进入日记或模型 |
| 模型结果 | Context 摘要、意图、Agent 工作性反思 | 保存结构化结果与调用审计，不保存原始推理链 |

AgentOne 不应把每个鼠标或滚轮事件直接持久化，也不录制连续屏幕视频。原始高频信号用于更新活动状态，日记保存的是语义片段和关键证据。

## 永久禁止采集

以下内容不能由用户开关覆盖：

- 密码与安全输入框
- 支付密码、卡号完整值和银行操作
- 短信或身份验证码
- API Key、访问令牌和私钥
- 系统识别为安全输入的文本

命中后，截图和 OCR 结果应在内存检查后立即丢弃，不写入日记、不发送模型。

## 可由用户授权的 Context

聊天正文、邮件正文、文档内容和选中文本可能对用户有价值，但也可能涉及他人或工作信息。它们属于可配置 Context：默认设置、应用级规则和当次敏感判断共同决定是否使用。

即使用户允许聊天 Context，密码、支付、验证码与凭证规则仍然优先。

## 本地与云端路由

产品允许用户在引导页选择：

- 云端模型优先
- 本地/离线模式
- 未来的自动路由

云端调用前必须完成：

1. 敏感 Context 拦截。
2. 与本次任务无关字段裁剪。
3. token、轮次和时长预算。
4. 工具白名单与调用目的标记。
5. 不把 API Key 放入 prompt、JSONL 或用户可见日志。

API Key 使用用户目录下权限为 `0600` 的文件保存，父目录权限为 `0700`。仓库的 `.gitignore` 同时排除常见凭证、Agent Home 和证据目录。

## 记忆真实性

- 原始日记不可静默编辑或覆盖。
- 用户反馈会以“纠正”事件追加，保留原判断与后续变化。
- 用户可以隐藏敏感片段；隐藏改变默认展示，不删除历史事件。
- 用户可以删除整个应用或自行处置 Agent Home。
- “Agent 日记”展示的是可复核的观察、假设、行动选择和保持沉默的原因，不声称展示模型原始 chain-of-thought。

## 发布前检查

任何提交或发布都必须确认：

```bash
rg --hidden -n \
  -g '!build/**' \
  -g '!.build/**' \
  -g '!AgentOneLifeRuntime/node_modules/**' \
  '(API[_ -]?KEY|SECRET|TOKEN|Bearer |/Users/|/var/folders/)'
```

还需要人工检查：

- `docs/images` 不含真实聊天、工作内容、URL、用户名或通知。
- 测试凭证只能是明确标注的假值。
- App 包、构建缓存、Agent Home、日记和证据截图不进入 Git。
- Issue 与安全报告不附真实 Context；按 `SECURITY.md` 私下提供最小复现。
