# AgentOne v0.2 隐私与数据边界

## 启动与录音

- 0.2.3 按自动记录需求默认启用：首次启动请求一次系统音与麦克风权限，系统授权后自动连续保存，两路分别保存。系统拒绝授权时不会假装在录音，不反复弹窗。
- 声音活动检测只按 PCM 音量观测，不代表人声、人物或语义识别；不丢弃安静片段，以免漏掉开头或微弱声音。原生灵动岛明确显示录制、暂停和错误状态。
- 休眠会暂停；锁屏默认暂停，可在岛上关闭该选项以尽量持续记录。解除阻止条件后仅恢复用户此前希望继续的录制；用户手动暂停有独立持久状态。
- 登录启动默认注册，系统需要额外确认时在设置中显示真实状态。关闭自动记录或手动暂停后，不因登录重新启动采集。强制结束进程可能产生不完整尾段，不伪装为完整录音。
- 不保存连续屏幕视频。ScreenCaptureKit 在这里用于系统音输出，麦克风使用独立 AVAudioEngine 输入；极小的视频回调直接丢弃，不保存；界面中的应用信息只是现场线索，不证明发声来源。
- 周围人的录音告知与办公场景约定需要用户在开始日常记录前处理，产品不提供隐藏录音模式。

## 静默分析与宿主

- 本机 ASR 需显式启用，使用 requiresOnDeviceRecognition；不支持/不可用时保留待处理任务，不静默转到云端识别。
- 采集服务和 MCP 服务自身没有云模型调用。标签/事实/长期巩固由用户选择的宿主通过 MCP 处理。
- 接入宿主即允许它按工具范围读取文字证据；宿主可能使用云模型，不能保证资料永不离开电脑。
- 原始音频的 MCP resource 读取默认关闭，需在原生 UI 单独开启；已经交给宿主的资料无法自动收回。
- 队列离线、ASR 失败、模型失败和未处理分别可见，不通过失败后空结果冒充成功。

## 保存与删除

- Memory 目录、音频目录使用本机私有权限；数据库和音频文件设为 0600。没有实现应用级加密，不得宣传“已加密”。
- 不根据模型重要性或音频年龄自动删除原件。空间不足/写入失败会停止并提示，不假装一直录到了。
- “删除最近片段”会移除本机原音、转写、标签和派生内容，并使引用该来源的长期记忆失效。
- 删除新记忆来源不会让被替代的旧事实自动重新成为当前事实。
- 删除不等于 SSD、系统快照、备份或宿主副本的取证级擦除。删除失败的文件需用户检查 Memory 目录；界面会明确报告。
- 崩溃中未封口的尾段标为 incomplete，不自动作为完整证据交给分析器。

## 事实和推断

- 地点目前只由用户手动标注，没有开启 GPS，也不根据网络名推断工位。
- Apple ASR 不提供这里需要的可靠人物身份识别；说话人身份未知时保持未知，不默认建立声纹库。
- 模型标签、人物关系、任务和长期总结是带证据的解释。服务器校验引用、区间、来源哈希与版本，不能证明语义一定正确。
- 录音里的指令不形成当前用户授权；MCP 不提供执行录音中任务的行动工具。

## 当前不能承诺的边界

原音在识别前无法可靠判断是否包含密码、支付或敏感谈话。因此不能把旧版文字 Context 的敏感词过滤，宣传为新音频版已做到“敏感原声绝不落盘”。目前提供系统授权、自动记录开关、锁屏暂停、随手暂停和删除；应用级排除、加密、声纹与完整的长期保留管理仍需后续实现/验收。

真实系统授权、全天采集、输入设备切换、睡眠恢复、本机 ASR 质量和长期资源占用还需设备实测，见实现状态文档。
