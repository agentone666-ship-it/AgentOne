# Thenvia 产品进展与路线图

2026-10-25。本页区分已实现的接口与后续验收目标，不代表功能发布日期承诺。新版代码仍在 [PR #2](https://github.com/agentone666-ship-it/Thenvia/pull/2)；主分支中的旧 App 尚在迁移。

## 当前预览

- 原生灵动岛与悬停展开、固定、状态和用户控制。
- 系统音与麦克风时间对齐后持续混合保存；模型分段/主题预览与可选智能触发。
- 可选本机转写、电脑事件记录和旧 Diary 导入。
- 本机插件导出、通用 MCP、宿主握手和服务自检分开显示。
- 获授权的系统自动地点接口；不可用时保留未知。
- 有来源的检索、上下文读取、分析任务队列和长期记忆写回接口。

上述项目已有代码与范围有限的测试/设备检查；定位授权、真实检索质量或具体宿主执行不得由合成数据替代。

## 接下来验证

1. **可靠留下现场**：长时间采集、休眠与锁屏恢复、设备切换、磁盘增长、能耗，以及覆盖缺口是否清楚。
2. **找对那段讨论**：获授权的中文真实对话、人物/主题混淆、模糊时间地点、跨月与多候选追问。
3. **接上已有 Agent**：至少一个具体宿主完成原话核对、事项交接、授权动作和实际产物回读。
4. **让新用户顺利体验**：固定安装包、首次配置、模型准备、错误恢复与宿主接入文档。

## 后续探索

- 可替换的语义检索与重排，和词面基线做真实数据对照。
- 跨片段讨论、决定变更与长期记忆巩固效果。
- 单色与小尺寸品牌图标、面向分发的签名、公证和升级。

新增能力以独立 Issue、实现和验收记录推进。欢迎通过 [场景建议](https://github.com/agentone666-ship-it/Thenvia/issues/new?template=feature_request.yml) 描述真实需求。
