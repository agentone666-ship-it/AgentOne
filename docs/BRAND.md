# Thenvia 留境 品牌资源

Thenvia（读作 then-VEE-uh）由 then 与 via 组合，表达让过去的情境成为下一步行动的依据。中文名为「留境」，原项目名为 AgentOne。

**Context carried forward.**

**你经历过的，不必再讲一遍。**

## 资源

- [仓库横幅](brand/hero.png)：首页与链接分享可用的 2:1 品牌图。
- [独立黑底图标](brand/icon.png)：产品头像与演示使用。
- [品牌组合展示](brand/identity-board.png)：中英文字标与配色方向。
- [横幅生成说明](brand/generation.json)：使用内置 image_gen 工具，以已选概念为参考生成。

标志用开放的圆角框表示留下的现场，连续曲线表示跨时间接续的线索。目标色为近黑 `#101715`、薄荷绿 `#98D8C0` 与暖白 `#F5F3EC`。

当前资源是 PNG 位图，包含轻微色阶，尚无精确纯色的 SVG 母版。App 内的小尺寸图标与应用名将按兼容迁移逐步更新；现有配置与数据不因品牌展示变化而重命名。

品牌资源不构成商标注册或独占权声明；当前仓库没有授予开源许可证。
