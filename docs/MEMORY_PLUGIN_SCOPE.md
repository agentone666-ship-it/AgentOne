# Personal Context Memory scope

The focused product is a local Context recorder plus a retrieval plugin for agents.

Keep the capture pipeline, privacy filtering, append-only diary, visibility controls, and historical search. These are necessary to collect accurate evidence and respect deletions or hidden entries.

The Codex plugin exposes read-only memory retrieval. It deliberately has no model credential, cloud provider, autonomous chat, avatar, daily digest, or proactive reminder capability. Those existing AgentOne features may be retired from the desktop UI after the collector and diary settings have been separated from them. Do not delete the diary or capture code while they still supply the plugin.

The first installed tool is `search_context`. Future memory tools should stay evidence-based and local, for example `get_context_event` or a deduplicated article view. They should not infer that a URL was read solely because a browsing event exists.
