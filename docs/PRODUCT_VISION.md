# AgentOne 产品愿景

## 一句话定义

AgentOne 是一个生活在用户数字世界里的 macOS 数字生命。它通过长期、经授权的 Context 理解用户具体在做什么，在注意力断裂时帮助用户回到原任务，也会用共同经历形成记忆、能力和个性。

## 首批用户

首批核心用户是 ADHD 与广义容易分心的人群，最先解决的刚需是：

> 走神之后，很难回忆自己刚才在做什么，也很难重新进入原来的认知现场。

产品不把用户的注意力问题简化成“自律不足”，也不依赖强硬的屏蔽、倒计时或羞耻感。AgentOne 应先理解用户原意图，再判断新活动究竟是相关检索、合理休息，还是已经脱离原任务。

## 产品价值观

### 1. 懂你，才有资格主动

主动性不能只来自定时器。AgentOne 的主动行为必须有 Context、记忆和当前状态作为依据，并且尊重不说话也是一种选择。

### 2. 记录具体经历，不做 App 使用统计

“打开了 Safari 42 分钟”几乎没有回忆价值；“为了论文中注意恢复的定义，阅读了两篇资料并写下一个结论”才是可回忆的 Context。

### 3. 提醒是一段关系，不是惩罚

提醒从 LUMA 的细微反应开始，随冲突持续时长逐级增强。中性、好奇的表达比判断式弹窗更符合朋友与助手的关系。

### 4. Memory 必须能被用起来

日记、周记、月记、长期记忆与 Skill 不是归档功能。它们要参与后续意图判断、提醒节奏、任务恢复、对话和主动服务。

### 5. 用户拥有 Context

没有 AgentOne 账号。Agent Home 在用户设备上，云模型只是用户选择的一种计算方式。未来支持迁移时，迁移的是用户拥有的文件，而不是服务端账户里的行为画像。

### 6. 真实优先于可编辑的完美

历史不被静默重写。识别错误、用户修正和后续理解都以追加事件保存，让 Agent 的记忆可复核、可成长。敏感片段可以隐藏，但不能伪造过去。

## LUMA 的人格与形象

LUMA 是“记忆微光体”：一个由意识核、记忆轨道和经历粒子构成的抽象生命体。它没有拟人的脸，但有可读的生命状态。

- **意识核**代表当下注意力。
- **记忆轨道**代表正在被调用的 Context 与长期关系。
- **经历粒子**会随共同经历积累，让不同用户的 LUMA 呈现不同轮廓。
- **情绪反应**用于降低提醒的命令感，不用于诱导用户依赖或制造内疚。
- **内心日记**展示经过整理的观察、假设、行动选择和“为什么没说”，不把模型原始推理链伪装成产品能力。

它的关系更接近朋友与 Jarvis 的结合：能干活，但不是满脑子只有提效；理解工作，也理解休息和生活。

## 核心使用闭环

1. 用户开始阅读、写作、搜索、沟通或娱乐。
2. AgentOne 将原始 Hook 聚合为持续活动状态，并补充语义 Context。
3. 意图引擎判断当前任务、相关支线、休息或冲突。
4. 高价值 Hook 保存关键证据并触发受预算约束的模型理解。
5. 冲突持续时，LUMA 从轻微反应升级到文字提醒与返回卡片。
6. 用户返回、确认相关、标记分心或表示想休息，反馈自动进入判断系统。
7. 当天 Context 形成回放；Agent 的观察形成独立日记。
8. 多日证据沉淀为 Memory 与 Skill，反过来提升下一次理解和主动服务。

## 两种模式

- **工作模式**：重视意图连续性、支线相关性、回到任务和安静陪伴。
- **生活模式**：允许边娱乐边聊天，理解休息、饮食、社交和个人偏好，并在合适时机提出惊喜。

模式不应只靠手动开关。用户可以明确告诉 LUMA “我想休息”，Agent 也应结合 Context 推断，但不确定时用低负担方式确认。

## 主动惊喜的边界

主动惊喜可以是：提醒一个被遗忘但重要的线索、在空闲时邀请复盘、把多日零散内容整理成可用材料、根据长期偏好准备餐食候选，或为即将发生的事情提前做准备。

任何会发送、购买、公开、改变权限或产生不可逆后果的行动，都必须在明确的用户授权与最终确认边界内完成。Agent 可以想、可以准备，但不能借“惊喜”绕过用户控制。
